# Security Policy

## Supported release

Security fixes are provided for the newest CleverPane release available on the official [Releases page](https://github.com/Changtey/CleverPane-updates/releases/latest).

## Reporting a security problem

Please report a suspected security issue privately by email to `Changwatre@gmail.com` with the subject **CleverPane security report**.

Include:

- CleverPane version.
- Windows and Microsoft Office versions.
- A clear description of the problem and its impact.
- Safe reproduction steps.
- Any non-sensitive log excerpt that is necessary to understand the issue.

Do not include passwords, API keys, OAuth tokens, private signing material, confidential documents, beneficiary data, financial data, or unnecessary personal information. Do not publish an exploitable security issue in a public GitHub issue before it has been reviewed.

## Release verification

The SHA-256 fingerprint for each installer is shown on its GitHub release. CleverPane's automatic update notice is digitally signed, and the app checks the installer size and SHA-256 fingerprint before starting it.
